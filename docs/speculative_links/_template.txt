# Speculative links: links that are correct, but not live until the next release, e.g. a docs page a PR adds.
#
# Copy this file to a name of your own in this folder (e.g. `catalog-tables-docs.txt`), one file per PR,
# so PRs never conflict here.

# Escape the dots and anchor the regex at the start, e.g.:
#
# ^https://rerun\.io/docs/howto/catalog-tables
#
# `pixi run link-check` and `pixi run link-check-pr` combine these files into `.lycheeignore`, which lychee reads.

# and the release workflow fails if any are left.
