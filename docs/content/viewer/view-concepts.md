View concepts explain behavior shared by several view types.
Use [view types](view-types.md) for guidance specific to a visualization.

- [Customize views](view-concepts/customize-views.md) explains visualizers, overrides, and component defaults.
- [Entity path filter](view-concepts/entity-path-filter.md) selects which entities a view displays.
- [Component mappings](view-concepts/component-mappings.md) select the data each visualizer reads.
- [Annotation context](view-concepts/annotation-context.md) shares labels, colors, and keypoint connections.
- [Text labels in 2D and 3D](view-concepts/labels.md) covers label placement and visibility in spatial views.
- [Visible time ranges](view-concepts/visible-time-ranges.md) control history, per-entity ranges, and linked time axes.
