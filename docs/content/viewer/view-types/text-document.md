Use a text document view to display a plain text or Markdown document alongside your data.
It is useful for experiment notes, instructions, and summaries that provide context for a recording.

See the [`TextDocumentView` reference](../../reference/types/views/text_document_view.md) for properties and examples.

## Data for this view

Log a [`TextDocument`](../../reference/types/archetypes/text_document.md) with plain text or Markdown.

## Configure the view

Use `monospace` and `word_wrap` in the view's format options to control display.
See the [TextDocumentView reference](../../reference/types/views/text_document_view.md).

## Limitations

A text document view displays one document at a time.
