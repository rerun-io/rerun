Use a dataframe view to inspect recording data as rows and columns.
It is useful when you need exact values rather than a plot, or want to compare components across entities and timestamps with a configurable query.

See the [`DataframeView` reference](../../reference/types/views/dataframe_view.md) for properties and examples.

## Configure the view

Configure the query's timeline, time range, columns, null filtering, latest-at behavior, and auto-scroll in the selection panel.
See the [DataframeView reference](../../reference/types/views/dataframe_view.md) for configuration options.
See [Dataframe queries](../../query-and-transform/dataframes/dataframe-queries.md) for the query model.
