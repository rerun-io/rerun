Use a 2D view to inspect images alongside points, bounding boxes, and lines.
It is useful for checking detections, segmentation results, and keypoints against the source image.

See the [`Spatial2DView` reference](../../reference/types/views/spatial2d_view.md) for properties and examples.

## Data for this view

Use images and 2D geometry such as points, boxes, line strips, and segmentation images.

## Configure the view

### Background and visible bounds

Set `background` to change the background color and `visual_bounds` to choose the visible region.

See the [Spatial2DView reference](../../reference/types/views/spatial2d_view.md) for a configuration example.

### Show history

See [Show history in 2D and 3D](../view-concepts/visible-time-ranges.md#show-history-in-2d-and-3d).


## Common tasks

### XY plots (Y against something other than time)

The X axis of a time series view is always a timeline.
To plot Y against another value, for example a trajectory or a phase plot, log the points as [`Points2D`](../../reference/types/archetypes/points2d.md) or [`LineStrips2D`](../../reference/types/archetypes/line_strips2d.md) and show them in a [2D view](../../reference/types/views/spatial2d_view.md):

snippet: views/spatial2d_xy_plot

The 2D view has its Y axis pointing down, like images, so flip the sign of Y.


### Covariance ellipses in 2D

[`Ellipses2D`](../../reference/types/archetypes/ellipses2d.md) draws ellipses aligned with the X and Y axes.
It has no rotation, so for a 2×2 covariance with correlation, draw the outline as a [`LineStrips2D`](../../reference/types/archetypes/line_strips2d.md):

snippet: views/spatial2d_covariance

### Segmentation images

Segmentation images are single channel integer images/tensors where each pixel represents a class id.
By default, Rerun assigns colors to each class id.
Define an annotation context to set the color of each class.

* Python: [`rr.SegmentationImage`](https://ref.rerun.io/docs/python/stable/common/archetypes/#rerun.archetypes.SegmentationImage)
* Rust: Log a [`rerun::SegmentationImage`](https://docs.rs/rerun/latest/rerun/archetypes/struct.SegmentationImage.html)

### Overlaying annotations on images

To draw boxes, labels, points, or masks on top of an image, log them under the same parent entity as the image, and show that parent in one 2D view:

```python
rr.log("camera/image", rr.Image(rgb))
rr.log("camera/detections", rr.Boxes2D(mins=mins, sizes=sizes, labels=labels, class_ids=class_ids))
rr.log("camera/mask", rr.SegmentationImage(mask, opacity=0.5))
```

Everything under `camera` is drawn in the same 2D coordinate space as the image, in pixel coordinates.
If the image is part of a 3D scene under a [`Pinhole`](../../reference/types/archetypes/pinhole.md), log the 2D annotations under the pinhole entity too.

- `opacity` on [`Image`](../../reference/types/archetypes/image.md) and [`SegmentationImage`](../../reference/types/archetypes/segmentation_image.md) makes them translucent.
  A segmentation image defaults to an opacity of 0.5 when there are other images in the view.
- `draw_order` on images, boxes, points, and lines sets what is drawn on top.
  Higher values are drawn on top of lower values.

The class IDs of the boxes and of the segmentation image use the same [annotation context](../view-concepts/annotation-context.md), so they get the same colors and labels.


## Limitations

The Y axis points down, as in image coordinates.
