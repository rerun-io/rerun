Use a graph view to display nodes and the directed or undirected edges between them.
It is useful for inspecting relationships, connectivity, and how a graph changes over time.

See the [`GraphView` reference](../../reference/types/views/graph_view.md) for properties and examples.

## Data for this view

Log [`GraphNodes`](../../reference/types/archetypes/graph_nodes.md) and [`GraphEdges`](../../reference/types/archetypes/graph_edges.md) for a directed or undirected graph.

## Configure the view

Set the background, visual bounds, and force settings to control graph layout.
See the [GraphView reference](../../reference/types/views/graph_view.md).
