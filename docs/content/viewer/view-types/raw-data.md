Use a raw data view to inspect the component values logged for a single entity.
It is useful for checking what was recorded when a visualization looks wrong, or for examining data that has no dedicated visualizer.

See the [`RawDataView` reference](../../reference/types/views/raw_data_view.md) for properties and examples.

## Data for this view

The view can inspect component data of one entity, including nested values.

## Configure the view

Choose which rows to show, the row density, and whether to show time navigation.
See the [RawDataView reference](../../reference/types/views/raw_data_view.md).

## Common tasks

Open a recording and add a Raw data view.
Select an entity to inspect its components and nested fields, then use the timeline panel to choose a timeline and move through changes.
See [Remap your data](../view-concepts/component-mappings.md) to visualize a compatible field in another view.



## Limitations

A Raw data view shows a single entity.
