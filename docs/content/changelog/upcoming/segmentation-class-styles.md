### Recolor and hide segmentation classes in the Viewer

The annotation context of a segmentation image can now be edited from the selection panel, as an override of its `SegmentationImage` visualizer.
Each class gets a color and a visibility checkbox, so classes can be recolored or hidden per view without changing the recording.
See [Annotation Context](../viewer/blueprints-and-views/annotation-context.md#segmentation-images).
