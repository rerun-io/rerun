---
title: "Hovering truncated table cells shows full content now"
hidden: true
type: misc
---

Hovering a value that is truncated, in a table cell or a list, now shows all of it in a tooltip.
Long text is shown in full, and nested data such as structs and lists is shown as an expandable tree.
