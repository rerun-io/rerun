### Experimental web view

The new [web view](../reference/types/views/web_view.md) shows a web page in the viewer, either from a URL or from raw HTML in the blueprint.
It is experimental and may change, and is only built with the `webview` feature.
So far, only the web viewer can show pages, in an `<iframe>`.
