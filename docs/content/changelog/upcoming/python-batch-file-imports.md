### Import multiple files with the Python SDK

Python's `log_file_from_path()` accepts an iterable of local paths.
Use it to [open multiple MCAP files as one recording](../logging-and-ingestion/import/mcap/working-with-mcap.md#opening-multiple-mcap-files-as-one-recording) and apply a saved Blueprint.
