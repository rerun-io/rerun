---
title: "Hovering a tensor shows a zoomed preview and element values"
hidden: true
type: misc
---

Hovering a tensor in the [tensor view](../reference/types/views/tensor_view.md) now shows a magnified view of the surrounding elements, along with the index and value of the element under the cursor, like hovering an image in the 2D view does.
