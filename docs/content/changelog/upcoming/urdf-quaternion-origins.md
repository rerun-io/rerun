---
title: URDF importer supports quaternions (URDF 1.1)
hidden: true
type: misc
---

Rerun's URDF importer now supports the `quat_xyzw` rotation field that was recently added to the [URDF specification version 1.1](https://github.com/ros/urdfdom#urdf-versioning) as an alternative to the `rpy` field.
