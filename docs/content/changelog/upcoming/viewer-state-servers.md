### Viewer state lists connected servers

`GetViewerState` — and with it the `rerun_get_viewer_state` MCP tool — now lists the Redap servers in the left panel, with the name, kind, and URL of every dataset and table on each, so an agent can open one by name.
See the [MCP reference](../reference/viewer/mcp.md).
