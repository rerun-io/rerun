### Clone view containers

Reuse a configured dashboard by right-clicking a container and choosing **Clone**.
The copy includes nested containers and views, preserving their layout and settings while allowing independent edits; the recorded data is shared.
See [Cloning a container](../reference/viewer/blueprints.md#cloning-a-container).
