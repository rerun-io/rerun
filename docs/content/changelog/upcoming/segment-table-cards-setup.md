### Set up cards for a segment table

The cards toggle of a dataset's segment table now always shows.
Without a card layout, the cards view explains what cards are, and offers to set them up with the [agent panel](../agents.md#agent-panel) or to [write the layout in Python](../viewer/blueprints/configure-table-blueprints.md).
