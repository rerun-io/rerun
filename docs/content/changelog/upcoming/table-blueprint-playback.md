### Segment preview time controls in blueprint

`rrb.table.PreviewsConfig` now has `play_state` and `playback_speed`, so a table blueprint can start all segment previews playing at a given speed.
See [Configure table layouts and segment previews](../howto/visualization/configure-table-blueprints.md#configuring-card-and-table-layouts).
