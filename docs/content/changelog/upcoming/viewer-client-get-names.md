### The `rerun_get_viewer_state` and `rerun_get_viewer_logs` MCP tools are now `rerun_get_state` and `rerun_get_logs`

The viewer's MCP tools take their names from the ViewerControl operations, which are now `GetState` and `GetLogs`, matching `get_state()` and `get_logs()` in Python and JavaScript.
