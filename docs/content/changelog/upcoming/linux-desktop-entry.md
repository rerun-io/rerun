---
title: Rerun icon in the Linux dock
hidden: true
type: misc
---

On Linux, the Viewer now installs a hidden `rerun.desktop` entry and icon under `~/.local/share`, so that GNOME shows the Rerun icon in the dock and Alt-Tab instead of a generic one.
Set `RERUN_DESKTOP_ENTRY=0` to disable this; see [troubleshooting](../getting-started/install-rerun/troubleshooting.md#running-on-linux).
