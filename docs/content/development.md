If you want to contribute and help develop Rerun, that work happens in the [Rerun repository](https://github.com/rerun-io/rerun). Also, make sure to join the [Rerun Discord](https://discord.gg/Gcm8BbTaAj).

## Build from source

[`BUILD.md`](https://github.com/rerun-io/rerun/blob/main/BUILD.md) explains how to set up your environment and build Rerun from source, including:

* [Validating your environment](https://github.com/rerun-io/rerun/blob/main/BUILD.md#validating-your-environment) with `pixi run check-env`, and the exact pixi and Rust versions it needs
* [Building the Python SDK](https://github.com/rerun-io/rerun/blob/main/BUILD.md#building-and-installing-the-rerun-python-sdk)
* [Building the C++ SDK](https://github.com/rerun-io/rerun/blob/main/BUILD.md#building-and-installing-the-rerun-c-sdk)
* [Building the web Viewer (Wasm)](https://github.com/rerun-io/rerun/blob/main/BUILD.md#building-for-the-web)
* [Improving compile times](https://github.com/rerun-io/rerun/blob/main/BUILD.md#improving-compile-times)

See also [`CONTRIBUTING.md`](https://github.com/rerun-io/rerun/blob/main/CONTRIBUTING.md).
