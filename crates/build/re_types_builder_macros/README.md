# re_types_builder_macros

Part of the [`rerun`](https://github.com/rerun-io/rerun) family of crates.

![MIT](https://img.shields.io/badge/license-MIT-blue.svg)
![Apache](https://img.shields.io/badge/license-Apache-blue.svg)

The `#[rerun_type]` attribute proc-macro used by Rerun's type definitions.

Re-exported by `re_types_builder_prelude`, which is what the definitions actually depend on.
You almost certainly want that crate instead.
