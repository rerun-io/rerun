JetBrains Mono Variable Font
============================

This directory includes the upright JetBrains Mono variable font, version 2.304.

The font contains a `wght` axis with named instances from Thin through ExtraBold.
Rerun installs it as the primary face for egui's monospace family while retaining egui's built-in fallback fonts for missing glyphs.
