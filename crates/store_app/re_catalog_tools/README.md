# re_catalog_tools

Part of the [`rerun`](https://github.com/rerun-io/rerun) family of crates.

![MIT](https://img.shields.io/badge/license-MIT-blue.svg)
![Apache](https://img.shields.io/badge/license-Apache-blue.svg)

Rerun catalog operations as tools for LLM agents.

`CatalogTools` is an `re_agent_tools::AgentToolbox`, so the same tools can reach an agent in-process (the viewer's agent panel, also on web) or over MCP (`re_rerun_mcp`).
