# Audio test assets

All `.aac` files are stored in git LFS.

- `sine_440hz_2s.wav`: a generated 2 second 440 Hz sine at 16 kHz mono.
- `toreador_song.aac`: Bizet's Toreador Song from Carmen, performed for [Musopen](https://musopen.org/) and released under CC0.
  Source: <https://commons.wikimedia.org/wiki/File:Bizet_-_Carmen_-_Toreador_Song_(French,_Musopen).ogg>.
  Transcoded to stereo 44.1 kHz AAC-LC in a raw ADTS stream at 128 kb/s.
