# Gaussian splat test assets

`cactus.ply` is a 3D Gaussian Splatting (3DGS) reconstruction of a cactus, with 139,410 splats.
It was trained with [Postshot](https://www.jawset.com/) by [steam studio / 3D SCAN STUDIO iris](https://note.com/steam_studio/n/ne9736d94f162), and released under the CC0 license (no restrictions).

The original file name was `cactus_splat3_30kSteps_142k_splats.ply`.
